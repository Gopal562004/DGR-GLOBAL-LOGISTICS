## ✈️ Core Services (Dedicated Pages)

1. **Air Freight Forwarding**: Priority and scheduled worldwide air cargo with guaranteed space allocation.
2. **Import & Console (Air & Sea)**: LCL & FCL consolidation across major international trade lanes.
3. **Custom Clearance**: Fast CHA processing at Mumbai Air Cargo Complex, Nhava Sheva (JNPT), and Indian ports.
4. **Warehouse & Distribution**: Secure storage, palletization, pick-and-pack, and nationwide delivery.
5. **Supplier of Hazardous Labels**: Certified Class 1 to 9 IATA, IMDG & ADR hazard diamond labels and placards.
6. **International Courier**: Express worldwide door-to-door courier for documents and commercial samples.
7. **Supplier of UN Approved Drums & Boxes**: Certified UN 4G/4GV boxes, steel tight-head drums (1A1), and HDPE jerricans (1H1/3H1).
8. **Hazardous Material Packaging**: Dangerous goods packing, dry ice (-78.5°C) thermal conditioning, and lithium battery packing.
9. **Consultancy & Documentation**: Shipper's Declaration for Dangerous Goods (DGD) and Material Safety Data Sheet (MSDS) audits.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18.18+)
- npm

### Installation & Run Locally
```bash
# 1. Clone the repository
git clone https://github.com/Gopal562004/DGR-GLOBAL-LOGISTICS.git

# 2. Navigate to project directory
cd DGR-GLOBAL-LOGISTICS

# 3. Install dependencies
npm install

# 4. Start the development server
npm run dev

# 5. Production build
npm run build
```
